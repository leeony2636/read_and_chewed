# 💡 LoRA: 거대 언어 모델을 가볍고 효율적으로 파인튜닝하는 방법

대규모 언어 모델(LLM)의 크기가 수십억~수천억 개의 파라미터로 거대해짐에 따라, 모델의 모든 가중치를 업데이트하는 기존의 **Full Fine-tuning** 방식은 막대한 GPU 메모리와 저장 공간을 요구하여 현실적인 한계에 부딪혔습니다. 

**LoRA (Low-Rank Adaptation, 2021)**는 사전 학습된 가중치(Pretrained Weight)를 고정(Freeze)하고, 매우 작은 저차원 행렬만을 학습함으로써 **Full Fine-tuning과 유사한 성능을 유지하면서도 메모리 및 저장 공간을 극적으로 줄인 혁신적인 기법**입니다.

---

## 📌 한 줄 요약
> 거대한 언어 모델 전체를 다시 학습하지 않고, **작은 저차원 행렬(A, B)만 학습하여 Full Fine-tuning과 비슷한 성능을 얻는 효율적 파인튜닝 기법**입니다.

### 📊 기존 Full Fine-tuning vs LoRA 비교

| 구분 | 기존 Full Fine-tuning | LoRA (Low-Rank Adaptation) |
| :--- | :--- | :--- |
| **파라미터 업데이트** | 모델의 **모든 파라미터** 수정 | 원본 가중치는 **고정(Freeze)**, **작은 저차원 행렬만 학습** |
| **저장 방식** | 작업(Task)마다 **새로운 수백 GB 전체 모델 저장** | 작업마다 **수십 MB 수준의 LoRA 어댑터 가중치만 저장** |
| **GPU 메모리** | 막대한 VRAM 필요 (일반 GPU에서 불가능) | VRAM 사용량 대폭 감소 (단일 RTX 3090/4090에서도 가능) |
| **학습 및 추론** | 학습 속도가 느리고 비용이 비쌈 | 학습 속도가 훨씬 빠르고, **추론 시 가중치를 합쳐 추가 지연 없음** |

## 💡 핵심 질문과 아이디어

### ❓ 핵심 질문
> *"정말 거대한 모델의 모든 파라미터를 전부 수정해야 새로운 작업을 학습할 수 있을까?"*

### 💡 저자들의 핵심 아이디어 (Low-Rank Hypothesis)
저자들은 모델을 새로운 작업에 맞게 학습할 때 실제로 필요한 **변화량($\Delta W$)의 내재적 차원(Intrinsic Dimension)이 매우 작다(Low-Rank)**고 가정했습니다.

따라서 원래의 거대한 가중치 행렬 $W_{original}$은 그대로 동결하고, 가중치 변화량 $\Delta W$를 두 개의 작은 저차원 행렬 $A$와 $B$의 곱으로 분해하여 학습합니다.

$$h = W_0 x + \Delta W x = W_0 x + B A x$$

*(여기서 $W_0 \in \mathbb{R}^{d \times k}$, $B \in \mathbb{R}^{d \times r}$, $A \in \mathbb{R}^{r \times k}$ 이며, 랭크 $r \ll \min(d, k)$ 입니다.)*

## 🏠 용어 및 일상생활 비유

| 용어 | 논문의 수학적/기술적 의미 | 일상생활 비유 |
| :--- | :--- | :--- |
| **Pretrained Model** | 이미 수많은 데이터로 사전 학습된 대형 LLM | 이미 완성된 아파트 |
| **Full Fine-tuning** | 모델 전체 파라미터를 다시 업데이트 | 아파트를 허물고 다시 건축하는 완전 재건축 |
| **LoRA** | 원본은 두고 필요한 변화량($\Delta W$)만 추가 학습 | 아파트 구조는 두고 **벽지와 가구만 교체하는 리모델링** |
| **Low-Rank ($r$)** | 전체 차원 대비 매우 작은 차원의 행렬 | 집 전체를 고치지 않고 **손잡이, 조명 등 필요한 부분만 교체** |

## 🎯 LoRA 논문의 최종 결론 5가지

1. **모델 전체를 다시 학습할 필요가 없다**
   * 기존 Fine-tuning처럼 모든 파라미터를 건드리지 않습니다. 원본 모델은 동결하고 필요한 부분만 효율적으로 수정합니다. (집 전체 재건축 $\rightarrow$ 필요한 방만 리모델링)

2. **변화량($\Delta W$)만 따로 학습하면 된다**
   * 원본 가중치($W$)는 그대로 유지한 채, 새로운 작업에 필요한 변화량($\Delta W$)만 별도로 추가합니다. (새 차를 사지 않고 튜닝 키트만 장착)

3. **작은 저차원 행렬($A$와 $B$)만 학습해도 충분하다**
   * 수천억 개의 파라미터 대신, 아주 작은 랭크($r=4, 8$ 등)를 가진 행렬 $A$와 $B$만 학습해도 Full Fine-tuning에 비견되는 우수한 성능을 얻습니다.

4. **메모리와 저장 공간을 극적으로 절감한다**
   * 원본 체크포인트는 하나만 보관하고 작업별로 작은 LoRA 어댑터 가중치만 저장합니다.  
   *(GPT-3 175B 기준, 체크포인트 크기를 **350GB에서 약 35MB 수준**으로 감소)*

5. **추론(Inference) 속도 지연(Latency)이 전혀 없다**
   * 학습 완료 후 $W = W_0 + BA$ 형태로 원본 가중치에 LoRA 가중치를 더해 하나로 합칠 수 있습니다. 따라서 추론 시 추가 연산이나 지연 시간이 발생하지 않습니다.
