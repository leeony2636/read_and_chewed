# 👁️ CNN 아키텍처의 발전과 컴퓨터 비전 (CNN Architectures & Computer Vision)

> **Overview:** 딥러닝 혁신의 시발점이 된 AlexNet(2012)부터 잔차 학습(Residual Learning)으로 깊은 신경망 학습을 가능하게 한 ResNet(2015)까지, 컴퓨터 비전을 혁신한 핵심 CNN 아키텍처를 분석합니다.

## 🌲 Part 1. ImageNet Classification with Deep Convolutional Neural Networks (2012) - Alex Krizhevsky et al.

### 🎯 핵심 요약

* **지치지 않는 '불포화 뉴런' (Non-saturating Neuron)**
  * 자극을 받으면 지치지 않고 끝까지 계산해 내어 AI의 학습 속도를 극적으로 끌어올린 활성화 함수 메커니즘.

* **초등학생 비유로 이해하는 '불포화 뉴런 vs 기존 포화 뉴런'**
<img width="695" height="453" alt="image (1)" src="https://github.com/user-attachments/assets/753460c4-7b51-46b3-984d-51a9fea8ae1a" />

| 구분 | 기존 포화 뉴런 (Saturating) | 불포화 뉴런 (Non-saturating / ReLU) |
| :--- | :--- | :--- |
| **작동 방식** | 공부를 너무 많이 시키면 "더 이상 못 받아들여!" 하고 뇌가 꽉 막혀버림 (값이 끝에서 평평해짐) | 자극을 주는 대로 지치지 않고 무한히 받아들여 끝까지 계산해 냄 |
| **학습 속도** | 기울기가 사라져서(Vanishing Gradient) 학습이 매우 느려지거나 정체됨 | 기울기를 일정하게 유지하여 학습 속도가 엄청나게 빠름 |
| **비유** | 수업 시간에 지쳐서 머리가 하얗게 질려버린 상태 | 아무리 어려운 문제를 줘도 계속해서 풀어내는 에너지 넘치는 상태 |

* **초등학생 비유로 이해하는 '불포화 뉴런 vs 기존 포화 뉴런'**

| 구분 | 옛날 뉴런 (포화) | 불포화 뉴런 (AlexNet 사용) |
| :--- | :--- | :--- |
| **특징** | 일정 수준을 넘어가면 반응이 둔해짐 | 자극을 받으면 한계 없이 끝없이 출력함 |
| **상태** | "머리가 꽉 차서 더 이상 공부 못하겠어요" | "아는 만큼 계속해서 정답을 맞춰볼게요" |
| **결과** | AI가 공부하는 속도가 매우 느려짐 | AI의 훈련 속도가 엄청나게 빠름 |

### 🚨 불포화 뉴런의 단점도 있어??

* **죽은 뉴런의 문제 (가중치 업데이트가 완전히 멈춘 뉴런)**
  * 기울기(Gradient)가 영원히 0이 됨.
* **출력값의 비중앙화**
  * 최적의 가중치를 찾아가지 못하고 지그재그 형태로 진동하여 학습속도가 느려질 수 있음.
* **출력값의 무한대 발산**
  * 포화 함수와 달리 상한선이 정해져 있지 않음.
  * 양수 영역 입력 값이 커지면 출력 값도 제약 없이 무한히 커짐 $\rightarrow$ **기울기의 폭주 문제**로 이어짐.
* **음수 영역 보완 함수들의 연산 비용 증가**
  * 컴퓨터 연산 자원을 많이 소모하여 학습 속도가 상대적으로 느려짐.
 
  * * **똑똑한 조별 과제를 위한 '드롭아웃' (Dropout)**
  AI 모델이 너무 똑똑해지면, 시험 문제(훈련 데이터)의 글자 크기나 점 위치까지 통째로 외워버리는 버릇(**오버피팅/과적합**)이 생겨요. 정작 진짜 시험(새로운 이미지)을 보면 틀려버리죠. 이를 막기 위해, 공부할 때마다 뉴런 몇 개를 무작위로 휴가 보내서 억지로 쉬게 만드는 기술이 바로 **드롭아웃**이에요.

<img width="679" height="558" alt="image (3)" src="https://github.com/user-attachments/assets/7ca5d7dd-8824-45a1-bfa4-6cdda291442d" />


| 상황 | 드롭아웃이 없을 때 | 드롭아웃을 켰을 때 🌞 |
| :--- | :--- | :--- |
| **공부 방식** | 한두 명의 천재 뉴런 뒤에 숨어서 대충 공부함 | 에이스가 언제 쉴지 모르니 **모든 뉴런이 다 열심히 공부함** |
| **문제점** | 기출문제집만 완벽히 외우고, 진짜 시험은 망침 | 정답을 꼼꼼하게 외우지 못해, 문제의 '핵심 원리'를 깨우침 |
| **효과** | 시험 문제 유형이 조금만 바뀌어도 오답 연발 | **처음 보는 이미지도 척척 맞춰내는 진짜 실력이 생긴** |

### 🧠 치열한 고민과 의문 (Read & Chewed)

#### ❓ 질문 (의문점)
> "드롭아웃 학습법은 좋아 보이긴 하는데 각각의 뉴런이 모두 일정하게 진행이 되는건지 아니면 뉴런마다 포화가 되는 상태가 있을텐데??"
> 
> **💡 초등학생 비유:** 신분이 같은 초등학생 100명이 같은 수학선생님한테 같은 시간에 같은 수업을 받지만 개중에 아픈 애들도 있고 결석한 애들도 있고 성적도 서로 같지 않잖아?? 어떻게 생각해?

#### 💡 AI 답변

* **1. "각각의 뉴런이 모두 일정하게 진행되는가?" $\rightarrow$ 아닙니다.**
  * 학습이 진행될 때 모든 뉴런은 완전히 '제각각' 움직입니다.
  * **학생 비유:** 같은 반 100명의 학생이 있어도 누구는 미적분을 금방 이해하고, 누구는 사칙연산도 헤맵니다.
  * **실제 신경망:** 각 뉴런이 가진 **가중치(Weight)**와 **편향(Bias)** 값이 초기화될 때부터 다르고, 역전파를 통해 업데이트되는 양도 다릅니다. 어떤 뉴런은 입력 데이터의 '색상'에 민감하게 반응하도록 학습되고, 어떤 뉴런은 '모양'에 반응하도록 학습되는 등 **역할 분담**이 일어납니다.
 
  * * **2. "뉴런마다 포화가 되는 상태가 있을 텐데?" $\rightarrow$ 맞습니다.**
  * 어떤 뉴런은 운 나쁘게 음수 영역으로 계속 밀려나 **'죽어버리거나(Dying ReLU)'**, 시그모이드 함수를 쓴다면 값이 끝으로 가 **'포화(Saturation)'** 상태가 됩니다.
  * **학생 비유:** 수업을 도저히 따라가지 못해 엎드려 자거나(죽은 뉴런), 이미 진도를 너무 다 깨우쳐서 선생님 말이 귀에 안 들어오는 상태(포화 뉴런)가 생기는 것과 같습니다.

* **3. 그렇다면 드롭아웃은 여기서 어떤 역할을 할까요?**
  * 신경망 내부의 뉴런들은 성적도 다르고 상태(포화/사멸)도 제각각입니다.
  * 드롭아웃은 이렇게 서로 다른 뉴런들이 특정 우등생 뉴런에게만 의존하려는 나쁜 습관을 깨부수고, 모든 뉴런이 스스로 제 역할을 하도록 강제 훈련시키는 학습법입니다.

> [!NOTE]
> **💡 최종 결론**
> * **동조화(Co-adaptation)를 방지하여 과적합(Overfitting)이 일어나지 않게 하기 위해 드롭아웃을 도입!**
> * 각각의 뉴런을 '학교 안의 학생'으로 비유하여 메커니즘을 명확히 이해함.

## 🌲 Part 2. Deep Residual Learning for Image Recognition (2015) - Kaiming He et al.

### 🎯 핵심 요약

* **ResNet의 원리 : 이미 아는 것은 지름길로 가자!**
  * 네트워크가 깊어질수록 발생하던 성능 저하(Degradation) 문제를 **지름길(Skip Connection/Shortcut)**을 통해 해결한 핵심 아키텍처.

<img width="569" height="390" alt="graph" src="https://github.com/user-attachments/assets/cc1f87fd-beb5-4c34-bd57-d5e2efdc5603" />

### 🧠 치열한 고민과 의문 (Read & Chewed)

#### 💡 이해한 방식 (직관적 해석)
* **기존 일반 네트워크 (Plain Network):** $1 \rightarrow 10$으로 가던 기존 방식은 다시 추가 학습을 하려면 $1 \rightarrow 11$로 전체 순서를 처음부터 다시 모두 거쳐야 하는 구조.
  * **문제점:** 네트워크가 깊어질수록 공부할 내용이 너무 많아져 길을 잃고 멍청해짐 (**Degradation 문제**).
* **레즈넷 (ResNet):** 이미 학습한 것($x$)은 지름길로 그냥 패스하고, 새로 추가된 차이점(잔차, $F(x)$)만 집중적으로 학습해 나가는 구조.
  * **효과:** 이미 아는 건 패스하고 새로운 차이만 공부하므로 152층까지 깊어져도 성능이 계속 똑똑해짐!
