# 💡 QLoRA: 4비트 양자화로 대형 언어 모델을 단일 GPU에서 파인튜닝하는 기법

GPT, LLaMA와 같은 대형 언어 모델(LLM)을 새로운 작업에 맞춰 파인튜닝(Fine-tuning)하려면 막대한 GPU 메모리와 비용이 필요했습니다. 예를 들어 LLaMA 65B 모델을 일반적인 16비트 방식으로 학습하려면 **780GB 이상의 GPU 메모리**가 필요하여 대부분의 연구자나 개발자가 접근하기 어려웠습니다.

**QLoRA (Quantized Low-Rank Adaptation, 2023)**는 모델 전체를 4비트로 정밀하게 압축하고 **LoRA 어댑터만 학습**하는 방식을 제안하여, 적은 GPU 자원만으로도 기존 16비트 학습과 거의 동일한 성능을 유지하는 혁신을 이뤄냈습니다.

---

## 📌 한 줄 요약
> QLoRA는 대형 언어 모델을 4비트로 압축하여 메모리 사용량을 최소화하고, 필요한 부분만 LoRA로 학습하여 적은 자원으로 고성능 파인튜닝을 가능하게 한 기술입니다.

---

## 🔑 QLoRA의 핵심 키워드 한눈에 보기

| 핵심 키워드 | 주요 의미 |
| :--- | :--- |
| **QLoRA** | 적은 GPU 메모리로 대형 언어 모델을 효율적으로 학습하는 통합 파인튜닝 기법 |
| **LoRA** | 기존 모델은 고정(Freeze)해 두고, 저차원 행렬을 이용해 필요한 부분만 추가 학습하는 기술 |
| **Quantization (양자화)** | 숫자 표현을 더 작은 비트(16bit $\rightarrow$ 4bit)로 저장하여 메모리 사용량을 줄이는 기술 |
| **NF4 (NormalFloat 4)** | 4비트 환경에서도 정보 손실 및 성능 저하를 최소화하도록 설계된 새로운 데이터 표현 방식 |
| **Double Quantization** | 양자화에 사용되는 압축 정보(상수)를 한 번 더 압축하여 메모리를 추가로 절약하는 기술 |
| **Paged Optimizer** | GPU 메모리가 부족할 때 CPU 메모리를 활용(Paging)하여 메모리 부족(OOM) 오류를 방지하는 기술 |

---

## ⚙️ QLoRA의 작동 원리와 핵심 메커니즘

QLoRA는 모델 전체의 가중치를 다시 수정하는 대신, **사전 학습된 원본 모델은 4비트로 압축하여 고정**하고 **LoRA 어댑터 파라미터만 16비트로 업데이트**합니다. 

이 과정에서 발생하는 성능 저하를 막기 위해 3가지 핵심 하드웨어/수학적 최적화가 적용됩니다.

1. **NF4 (NormalFloat 4):** 정규 분포를 따르는 LLM 가중치 특성에 맞춰 최적화된 4비트 데이터 타입
2. **Double Quantization (이중 양자화):** 양자화 상수를 추가로 양자화하여 파라미터당 0.37비트 절감
3. **Paged Optimizers:** CUDA 핀 메모리를 통해 GPU 메모리 피크 발생 시 데이터를 CPU 메모리로 잠시 이동

## 🏠 QLoRA 핵심 내용 일상생활 비유

| 논문 내용 | 일상생활 비유 |
| :--- | :--- |
| **기존 Full Fine-tuning** | 오래된 교과서를 새로 만들기 위해 모든 페이지를 처음부터 끝까지 다 다시 쓰는 것 |
| **QLoRA의 학습 방식** | 교과서 전체를 다시 쓰지 않고, **수정이 필요한 부분에만 포스트잇(메모)을 붙여 내용을 보완**하는 것 |
| **Quantization (양자화)** | 여행 가방에 옷을 잘 압축하고 접어서 넣어 **같은 공간에 더 많은 짐을 담는 것** |
| **Paged Optimizer** | 공부하다 책상이 좁아지면 **옆의 보조 책상(CPU)을 함께 활용**하여 공부를 중단 없이 계속하는 것 |

---

## 🎯 QLoRA 논문의 최종 결론

1. **GPU 메모리 비용 극적 절감:** 기존 대형 언어 모델 학습에 필요했던 막대한 GPU 메모리 부담을 대폭 줄였습니다.
2. **혁신적인 3대 기술 도입:** `NF4`, `Double Quantization`, `Paged Optimizer`를 도입하여 4비트 환경에서도 성능 저하 없는 효율적 학습을 실현했습니다.
3. **16비트 수준의 성능 유지:** 65B 규모의 모델도 단일 소비자용 GPU(예: 24GB/48GB VRAM) 환경에서 기존 16비트 Full Fine-tuning 수준의 우수한 성능으로 파인튜닝할 수 있음을 증명했습니다.

> 💡 **한 줄 결론:** QLoRA는 **'모델 압축(4-bit Quantization) + 효율적 학습(LoRA) + 메모리 스파이크 방지(Paged Optimizer)'**를 하나로 묶어, 누구나 대형 언어 모델을 가볍게 다룰 수 있도록 만든 논문입니다.
