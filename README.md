## 💡 주요 정리 방식

* 🩺 **일상생활 속 직관적인 비유**
  - 복잡한 머신러닝 메커니즘을 '100명의 의사 의견 종합', '오답 노트를 쓰는 팀플레이'와 같이 일상적인 예시로 풀어내어 쉽게 읽히도록 했습니다.
* 🎨 **이해를 돕는 시각적 도해와 그림**
  - 딱딱한 텍스트 나열 대신, 알고리즘의 발전 과정과 병렬·직렬 구조의 차이점을 그림이나 도표로 시각화하여 구조적인 흐름을 담았습니다.
